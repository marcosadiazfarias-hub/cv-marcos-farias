🚀 Portfólio Profissional - Marcos FariasEste é o repositório do meu portfólio profissional web. O site foi desenvolvido para apresentar minha trajetória, habilidades e formação como Desenvolvedor Backend Java Sênior, combinando um tom profissional e moderno com um toque de bom humor.🌟 Principais FuncionalidadesDesign Responsivo (Mobile-First): Layout perfeitamente adaptável para visualização em smartphones, tablets e desktops.Tema Claro / Escuro Automático (Dark Mode): O site detecta automaticamente a preferência de tema do sistema operacional do usuário e se ajusta para as paletas Slate/White (Claro) ou Stone/Dark (Escuro).Single-Page Application (SPA): Navegação fluida e rápida com rolagem suave (smooth scroll) entre as seções.Arquitetura Modular em Arquivo Único: Todo o código React foi estruturado de forma inteligente, dividindo as responsabilidades em componentes menores (Header, Hero, About, Skills, etc.) para fácil manutenção.Ícones Modernos: Utilização da biblioteca lucide-react para iconografia limpa e escalável.🛠️ Tecnologias UtilizadasReact: Biblioteca JavaScript para construção da interface de usuário.Tailwind CSS: Framework CSS Utility-first para estilização rápida, responsividade e gerenciamento de temas (Dark Mode).Lucide React: Biblioteca de ícones SVG de código aberto.📂 Estrutura das SeçõesO portfólio é dividido nas seguintes áreas:Header (Navegação): Menu fixo no topo com links rápidos e design translúcido (backdrop-blur). Inclui menu hambúrguer para dispositivos móveis.Hero: Apresentação de impacto com título, resumo rápido, botões de Call to Action (Contato e GitHub) e o avatar cartoonizado.Sobre Mim: Detalhamento da experiência, perfil comportamental, foto em P&B e citações inspiradoras.Skills (Arsenal Técnico): Grade visual com tecnologias categorizadas (Backend, Arquitetura, Integração, Cloud e Banco de Dados).Trajetória (Experiência): Linha do tempo estilizada destacando os projetos em empresas de alta criticidade (Accenture, Santander, Itaú, etc.).Formação Acadêmica: Cards de educação e certificações, com destaque visual para os cursos em andamento vs. concluídos.Footer (Contato): Seção de fechamento com foto de perfil corporativa, e-mail, telefone e links para redes sociais (LinkedIn/GitHub).⚙️ Como atualizar os dados do siteO código foi construído pensando na facilidade de manutenção. Se você quiser adicionar uma nova habilidade, experiência ou curso, não precisa mexer no layout! Basta atualizar as constantes localizadas no início do arquivo App.jsx:SKILLS: Adicione ou remova tecnologias das categorias.EXPERIENCES: Adicione novos blocos de experiência profissional com título, empresa, descrição e tags.ACADEMIC: Atualize seus cursos, pós-graduações e MBA. Mudar o status para 'Concluído' mudará automaticamente a cor do selo (badge) no site.QUOTES: Troque ou adicione novas frases inspiradoras.Exemplo de como adicionar um novo curso:const ACADEMIC = [
  // ... cursos existentes ...
  {
    course: "Nova Certificação AWS",
    institution: "Amazon Web Services",
    type: "Certificação",
    status: "Concluído"
  }
];
🚀 Como executar o projeto localmentePara rodar este projeto em sua máquina local, você precisará ter o Node.js instalado.Clone o repositório:git clone [https://github.com/TarjaBlack/developer-marcos.git](https://github.com/TarjaBlack/developer-marcos.git)
Acesse o diretório do projeto:cd developer-marcos
Instale as dependências:npm install 
Inicie o servidor de desenvolvimento:npm start 
# ou se estiver usando Vite:
npm run dev
O site estará disponível no seu navegador, geralmente no endereço http://localhost:3000 ou http://localhost:5173.Nota sobre as Imagens: Certifique-se de que as imagens de perfil e logo (1780665451143.png, 20260625_102255-IMG_STYLE.jpg e 20260625_215054-IMG_STYLE.jpg) estejam localizadas na pasta public do seu projeto React para que sejam carregadas corretamente.📬 ContatoMarcos André Díaz Farias Desenvolvedor Backend Java Sênior✉️ E-mail: m.diazfarias@gmail.com📱 Telefone: (48) 98862-1897💼 LinkedIn: linkedin.com/in/marcosdiazfarias🐙 GitHub: github.com/TarjaBlackFeito com ☕ e muito código. 2026.
